# Sample data

`synthetic_knee_CT.zip` — synthetic left-knee CT (DICOM, uncompressed, 0.7 × 0.7 × 1.0 mm, 290 slices) built from the CC0 template meshes, with one small detached fragment near the lateral tibial rim.

Use it in the *Patient scan* tab: load the zip → *Extract bones from CT* → check the automatic landmarks → *Plan on this patient's knee*.
